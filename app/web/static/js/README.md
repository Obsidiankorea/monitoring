# 지도 화면 코드 (map.html)

`map.html`(구조) + `css/map.css`(모양) + 이 폴더의 `js/NN-이름.js`(동작). 예전에는 한 파일(7천 줄)이었고, 줄 하나 바꾸지 않고 구역 경계에서 잘랐다.
빌드 도구 없이 일반 `<script src>` 로 **번호 순서대로** 불러 모든 변수가 한 공간을 공유한다 — 파일 사이 호출은 예전처럼 그냥 부르면 된다.

| 파일 | 내용 |
|---|---|
| 01-core | 층, 테마, 투영, 틀, 경계, 색, 라벨, 범례, 머리, 층 메뉴 |
| 02-data | 자료 받기, 재생 흐름, 타임라인, 시군 확대, 지도 위치(카메라) |
| 03-cards | 오른쪽 카드(종합 화면 판) |
| 04-case | 재현 사례(`?case=`) |
| 05-layers | 레이어, 기상특보, 바다 위젯, 관측소 |
| 06-river | 하천 · 댐 · 보(홍수통제소) |
| 06b-tide | 조위(해양조사원) — 해안 표식, 팝업 게이지 · 물결, 대조기 |
| 07-select-ai | 시군 고르기, AI 상황판단 팝업 |
| 08-help | 도움말, 용어 백과 |
| 09-prefs | 설정(업데이트 · API 절약 · AI 알림 · AI 위키 · API 키) |
| 10-show | 화면 재생, 재생목록 |
| 11-misc | AWS 비활성화, 마우스, 기준 근접 알림, 초단기예측 이미지 재생, **boot()(맨 끝)** |

## 지킬 것
- 첫 파일 말고는 맨 위에 `"use strict";` 한 줄(스크립트마다 따로 켜진다).
- 같은 이름의 최상위 `let/const/function` 을 두 파일에 두지 않는다(불러올 때 오류).
- 불러오는 도중(최상위)에 **뒤 파일**의 함수를 부르지 않는다 — 함수 끌어올림(호이스팅)은 파일 안에서만 된다. 클릭 · 타이머 안에서 부르는 것은 괜찮다. `boot()` 는 11 맨 끝이라 모두 불러온 뒤 돈다.
- 새 파일을 더하면 `map.html` 에 `<script src="js/NN-이름.js?v={{V}}">` 를 번호 순서로 적는다. `{{V}}` 는 서버(`/map.html`)가 파일 수정 시각으로 바꿔 준다(옛 파일 캐시 방지).
- 고친 뒤 `python tools/check_map.py` (파일 · 순서 · 이름 겹침 · 문법 검사) 와 브라우저에서 한 번 열어 보기.
