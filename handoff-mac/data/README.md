# 데이터 파일

원본 프로젝트에서 그대로 가져온 참조 데이터. **다시 만들기 번거로우니 재사용할 것.**

## `aws_stations.json` — 경남 AWS 관측지점 56곳

```json
[{"stn": 155, "name": "창원", "sigun": "창원"}, ...]
```

`awsh.php`·`nph-aws2_min` 응답에서 경남 지점만 걸러낼 때 쓴다.

**시군 대표지점**(시군별 대표값 계산용):

```
창원 155  진주 192  통영 162  사천 917  김해 253  밀양 288
거제 294  양산 257  의령 263  함안 920  창녕 919  고성 918
남해 295  하동 932  산청 289  함양 264  거창 284  합천 285
```

⚠️ 기온표 등에서 **가야산(311)·지리산(872)은 제외**할 것 — 산악이라 늘 극값을
독식해 정보가 되지 않는다. (강수량 다우지점에서는 오히려 의미가 있으니 그대로 쓴다)

## `gyeongnam_grids.json` — 읍면동 ↔ 격자 매핑 206곳

```json
{"grid_width": 149, "sigun_grids": {"창원": [{"xy": [91, 77], "emd": "의창구"}, ...]}}
```

초단기예측 격자(`nph-dfs_vsrt_grd`) 응답에서 읍면동 값을 뽑을 때 쓴다.

```python
index = (Y - 1) * grid_width + (X - 1)     # grid_width = 149
```

- 응답은 **37,697개 float** = 149 × 253 (동네예보 5km 격자)
- `-99`는 결측/무강수
- **창원은 5개 구를 하나로 병합**해 두었다
- ⚠️ 읍면동은 모델의 계산 단위가 아니라 **약 5km 격자칸에 붙인 이름표**다.
  같은 격자에 든 이웃 읍면동은 값이 같게 나온다 — 표에서 여러 읍면동이 똑같은
  값으로 보이는 게 버그가 아니다.
