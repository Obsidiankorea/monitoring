## 이 프로젝트가 하는 일

경상남도 18개 시군의 기상 상황을 **웹 대시보드**로 보여주고, 위험 조건에서
**텔레그램으로 알리는** 맥미니 상주 서버.

1. 정해진 시각(또는 주기)에 기상청 API에서 자료를 받아 화면에 표출 — 강수량·특보·예측 이미지
2. 조건 감시 → 텔레그램 알림
3. 참고 문서(사진·PDF) 열람

자세한 요구사항은 `docs/01-requirements.md`.

## 절대 규칙

1. **비밀은 저장소에 넣지 않는다.** API 키·텔레그램 토큰은 `.env`(또는
   `config/api_keys.txt`)에만 두고 `.gitignore`에 등록한다. 코드의 기본값
   딕셔너리에 넣는 것도 금지 — 그건 커밋된다.
2. **밖으로 나가는 동작은 기본 꺼짐.** 텔레그램 전송처럼 외부로 나가는 기능은
   기본값을 끔으로 두고 사용자가 켜게 한다. 테스트 중 실제 채팅방으로 보내지 않는다.
3. **조회 실패와 '데이터 없음'을 구분한다.** 이걸 뭉개면 오보가 나간다.
   실패는 `None`, 없음은 빈 값. `except: return {}` 금지. → `docs/05-pitfalls.md`
4. **추측한 값을 사실처럼 쓰지 않는다.** API 응답 형식·컬럼 위치·시각 기준은
   실제로 한 번 호출해 확인하고, 알아낸 것은 문서에 적는다.
5. **한글(HWP) 자동화는 이 프로젝트에 없다.** macOS에서 불가능하다. 관련 요청이
   오면 Windows 원본 프로젝트의 일이라고 알린다.

## 코드 규칙

- **주석은 한국어로, '왜'를 적는다.** 무엇을 하는지는 코드가 말한다. 주석에는
  *왜 이렇게 했는지*, 특히 **직관과 다른 이유**를 적는다.
- 함정을 만나면 해당 코드에 `⚠️`로 표시하고 `docs/05-pitfalls.md`에도 한 줄 남긴다.
  같은 함정에 두 번 빠지지 않는 것이 이 프로젝트에서 가장 값진 자산이다.
- 외부 API 호출은 **타임아웃 필수**, 재시도는 **1회까지**. 감시 루프가 밀리면
  복구 시 알림이 쏟아진다.
- 시각은 전부 **KST**. UTC 변환하지 않는다(기상청 API가 KST를 쓴다).

## 개발 명령

> 아직 뼈대가 없다. 첫 스캐폴딩을 만든 에이전트가 이 표를 실제 명령으로 채울 것.

```bash
uv sync                      # 의존성 (또는 pip install -r requirements.txt)
uv run uvicorn app.main:app --reload --port 8000   # 개발 서버
uv run pytest                # 테스트
uv run ruff check . && uv run ruff format .        # 린트·포맷
```

## 작업 방식

`docs/06-workflow.md`의 **명세 → 계획 → 구현 → 검증** 절차를 따른다.
요약하면:

- 한 번에 하나씩. 여러 기능을 섞어 고치지 않는다.
- 바꾼 것은 **실제로 돌려서 확인**하고, 확인한 내용을 보고한다.
  "동작할 것입니다"가 아니라 "돌려 보니 이렇게 나왔습니다".
- 확인하지 못한 부분은 **확인하지 못했다고 말한다**.
- 커밋 메시지는 한 줄 요약 + 왜 바꿨는지.

## 자주 하는 실수 (이 도메인 특유)

- 특보 레벨 파싱에서 **`중대경보`를 먼저 떼지 않으면** `폭염중대경보`가 통째로 누락된다.
- API가 주는 레벨 문자열은 `경보`/**`주의`**다. `주의보`가 아니다.
- 예비특보의 `TM_EF`는 **시각이 아니라 시간대 코드**다(`1159` = 오전 09~12시).
- `RN_DAY`는 자정에 전날 총량을 보여주고 01시에 0으로 리셋된다.
- 초단기예측 `RN1`은 **선행 1시간 누적**이라 10분 간격으로 조회해도 값이 1시간마다만 바뀐다.
  누적을 낼 때 칸을 그냥 더하면 3배가 된다.
