# 조사 — 대만 토석류 경계

대만 농업부 農村發展及水土保持署(옛 水土保持局)의 토석류 경계 · 대피 체계. 2026-11-13 웹 조사. 쓰임새는 [[00-로드맵]].

> [!warning] 확인하지 못한 것
> NCDR 災害情資網의 화면 구성(동적 로드) · 보전 주민의 실제 대피율 · 대규모 붕괴의 황 · 적색 수치 조건 · 유효누적강우량 공식(공식 페이지에는 그림만) · 村里長의 법정 권한 · 署의 SOP 문서 4종 본문(발령 주기 · 해제 조건 · 명부 갱신 규정이 여기 있을 것 — [목록](https://246.ardswc.gov.tw/Rule/SOP)). 성과 통계는 2013년 논문 값이고 최근 수치는 찾지 못했다.

## 1. 土石流潛勢溪流(잠재 계류) 제도

- **규모**: 1,753개 계류(17개 현 · 시, 159개 향진, 692개 촌리). 대규모 붕괴 잠재구역 94곳. 2026-05-14 갱신 기준. [출처](https://246.ardswc.gov.tw/ImportantEvents/KeyData)
- **보전 대상**: 52,812명(단위는 가구가 아니라 사람).
- **공개 목록의 열**: 현 · 시, 향진, 촌리, 계류 번호, 주요 지표물, **참고 우량관측소 2곳**, 경계값. [목록](https://246.ardswc.gov.tw/DebrisFlow/List)
- 계류별 보전 가구 수 · 영향 범위 · 대피소의 등록 형식은 확인 못 함(대피도는 따로 조회).

## 2. 경계 기준값

| 항목 | 내용 |
|---|---|
| 지표 | RTI = 유효누적강우량(Rt) × 강우강도(I) |
| 문턱 | 참고 우량관측소의 과거 강우 · 재해 기록으로 발생 확률 70% 인 RTI70 을 구함 |
| 단순화 | I = 10mm/hr 로 놓고 누적강우량 R70 으로 환산 |
| 등급 | 50mm 단위, 200~650mm, 10단계 |
| 정기 검토 | 연 1회, 우기 뒤부터 다음 우기 전까지 |
| 즉시 검토 | 중대 토사재해 · 진도 5강 이상 지진 · 기존 경계구역 안에 새 계류 추가 |
| 지진 뒤 하향 | 5강은 R60 기준(약 1~2단계), 6약 이상은 R50 기준(약 2~4단계) |
| 복귀 | 지진 뒤 5년 안에 기준 초과 강우를 재해 없이 넘기면 원래 값으로(5강 1회, 6약 이상 3회) |

기준 검토와 경계 발령 모두 중앙(水土保持署)이 한다. 출처: [AlertSet](https://246.ardswc.gov.tw/DebrisFlow/AlertSet) · [학회지 논문(陳振宇 2013)](https://www.cswcs.org.tw/AllDataPos/JournalPos/VOL44/NO1/44(1)050-065.pdf)

## 3. 황색 · 적색 경계

- **황색**: 예측 강우 > 경계값. 지방정부가 대피를 권고하고, 거동이 불편한 사람 · 정기 진료가 필요한 사람은 예방 대피.
- **적색**: 실제 강우 > 경계값. 지방기관이 권고 또는 강제로 대피시키고 수용.
- **대상**: 영향 범위 안의 보전 주민만(마을 전체 대피가 아니다).
- **법적 근거**: 災害防救法 제24조(통신사 보도로 확인, 조문 원문은 읽지 않음).
- **현장 사례(2023년 가오슝)**: 강제 대피 55명, 권고 373명. 적색 전환 뒤 2시간 안에 보전 주민 대피를 끝내도록 했다.
- **성과 통계(2007~2011년 평균)**: 적중률 45.4%, 오보율 75.2%, 공간 포괄률 62.6%. 모라꼿 태풍이 온 2009년은 72.6% · 58.3% · 77.8%.

출처: [防災指南](https://eoc.taichung.gov.tw/media/1250611/土石流及大規模崩塌防災簡介.pdf) · [CNA 2026-08](https://cna.com.tw/news/ahel/202608220035.aspx) · [CNA 2023-08](https://www.cna.com.tw/news/asoc/202308040139.aspx)

## 4. 대규모 붕괴 경계

- 강우와 현지 관측을 함께 쓴다. 2001~2016년 사례 28건으로 유효누적강우량 임계선을 만들고 79건으로 검증, 대피 준비 시간을 빼서 경계선으로 환산. [출처](https://246.ardswc.gov.tw/Landslide/AlertSet)
- 관측 관리값: 지표 신축계 0.5~20mm/일, 지표 경사계 5~50초/일, 관내 경사계 0.5~10mm/일.
- 구역별 값(2023년 표): 43곳에 300~900mm. 국부 변형이 이미 생긴 곳과 지진 뒤 조정한 곳을 표에 주석으로 단다.

## 5. 현장 연결

- **防災專員(주민 방재 전문원)**: 2005년 시작, 대상 613개 촌리, 임기 3년. 간이 우량통 값을 문자로 회신하고, 경계값에 닿으면 스스로 대피를 알린다. 황 · 적색을 담당 보전 주민에게 전달하고 대피 상황을 보고한다. 누계 3,819명. [출처](https://246.ardswc.gov.tw/SelfPreparedness/Guardian)
- **대피계획**: 현황 조사 → 대피로 · 대피소 겹쳐 그리기 → 村里長과 현장 교정 → 村里長 서명으로 확정. 보전 주민 연락처는 村里長에게서 받는다. [출처](https://246.ardswc.gov.tw/SelfPreparedness/AutonomyCommunity)
- 專員 관측값이 발령 판단에 자동 반영되는지는 확인 못 함.

## 6. NCDR 통합 플랫폼

- **災害情資網**: 주제도 그룹 전환, 관측점 번호로 위치 찾기, 조회 조건을 담은 공유 URL. [사이트](https://eocdss.ncdr.nat.gov.tw/web/)
- **WATCH**: 예경보를 태풍 · 호우 · 가뭄 · 고온 등 주제로 재편, 화면 요소마다 독립 API 로 제공.

## 7. 한계와 가져올 설계

**한계**(陳振宇 2013): 오보율이 높고 재해의 정확한 위치 · 규모를 잡지 못한다 · 토사재해의 45.9% 가 대피하기 어려운 시간대(21~07시)에 났다(모라꼿 때 60.9%) · 대피에 3~8시간이 필요하다 · 지상 관측소에 의존한다.

**가져올 설계**
1. **예측 초과와 실측 초과를 다른 단계로 나누기.** 황색(권고) / 적색(강제). % 대조를 "예보 기준 %"와 "실황 기준 %" 두 줄로.
2. **지구마다 대표 관측소 2곳을 명시하기.** 어느 관측소 값으로 판정했는지 보이면 판정을 검증할 수 있다.
3. **기준값에 조정 이력과 사유를 붙이기.** 산불 · 지진 · 피해 뒤 임시 하향과 복귀 조건을 지구 속성으로.
4. **야간 앞당김 알림.** 일몰 전 시점의 "밤사이 예보 기준 초과" 알림을 따로 둔다.
5. **호우가 끝난 뒤 적중 · 오보 · 포괄률을 자동 집계하기.**
