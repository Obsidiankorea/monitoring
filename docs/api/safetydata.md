# 재난안전데이터공유플랫폼

> [!info] 키는 포털 회원가입 후 API 마다 활용신청
> 호출 경로는 `/V2/api/DSSP-IF-xxxxx`, 공통 변수 `serviceKey · numOfRows · pageNo · returnType`. 공공기관 데이터는 공공누리 3유형.
> 후보 평가와 샘플 값은 조사 노트(`research_notes/lane-1/06-safetydata-catalog.md`, git 에는 안 올림). **실제 호출은 한 번도 안 함.**

## 신청 전에 할 것
1. 본인 계정으로 위험저수지(3749)와 제방정보(1314) 활용신청 → 승인 방식 · 한도 · IP 등록 필요 여부를 위 `한도` · `IP등록` 칸에 옮긴다.
2. 승인 뒤 첫 주는 호출 수를 로그로 세어 `하루호출`을 실측으로 바꾼다.
