# API · 키 목록

설정 › 시스템 › API 키 화면의 각 줄에 만료일 · 발급처 · 이 문서 링크가 붙는다. **화면에 보이는 정보는 각 문서 맨 위 `---` 칸에서 읽어 온다** — 문서를 고치면 화면도 바뀐다(코드 수정 없음).

| ORG_API_KEY | [[kma-apihub]] | 기상청 API허브 | 사용 중 |

| TELEGRAM_* | [[telegram]] | BotFather | 사용 중 |

## 문서 맨 위 칸 (이것만 지키면 된다)
`이름` · `키이름` · `발급처` · `관리URL`(로그인해서 키 보는 곳 — 바로 가는 주소) · `계정`(아이디만, **비밀번호·키 값은 절대 적지 않는다**) · `신청일` · `승인일` · `만료`(`2027-03-31` 꼴이면 D-day 계산, 글이면 그대로) · `한도`(일/분 제한과 출처, 모르면 "확인 못함") · `IP등록` · `상태` · `쓰는곳`.

## 안 잊는 규칙
1. **새 API 를 붙일 때** 코드보다 먼저 이 폴더에 문서를 만든다(위 칸을 채운 채로). 코드는 `app/apikeys.py` 의 `EDITABLE` 에 한 줄.
2. **만료는 날짜로** 적는다. 30일 안으로 다가오면 설정 화면에 붉게 뜬다. 비어 있으면 "만료일 미기재"로 뜬다.
3. 키 값 · 비밀번호는 문서에 쓰지 않는다 — 문서는 git 에 올라간다. 키는 `config/api_keys.txt`(git 제외) 뿐.
4. 못 찾겠던 메뉴 경로는 **찾은 그날** 문서에 한 줄로 적는다(기상청이 특히).

## 호출 한도 · 주기 (비올 때만 부를지 정하는 칸)
API 마다 아래 표를 문서 안에 둔다. 빈칸 대신 **"확인 못함"** 을 적는다(모르는 건지 안 적은 건지 구분하려고).

| 칸 | 뜻 |
|---|---|
| 호출단위 | 한 번에 무엇이 오나 — 전국 1회 / 지점마다 / 시군마다 |
| 원천갱신 | 자료가 바뀌는 주기 (정적 · 1일 · 10분 …) |
| 평시주기 → 비상주기 | 비 안 올 때 / 올 때 부르는 간격 |
| 비상조건 | 새 숫자를 만들지 않는다 — 이미 있는 **특보 발효** 또는 **시군 단계가 평시가 아닐 때** |
| 하루호출 | 호출단위 수 × (24시간 ÷ 주기). 한도와 비교 |

주기 고르는 틀: **정적**(제원·위치·침수범위)은 시작할 때 1번 · **준정적**(조석예보 · 피해 이력)은 하루 1~2번 · **실시간**(수위 · 우량 · 경보)은 평시 낮은 빈도 + 비올 때만 촘촘히. 한도를 모르는 API 는 첫 주 동안 호출 수를 로그로 세어 `하루호출`을 실측으로 바꾼다.
