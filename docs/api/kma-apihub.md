# 기상청 API허브 (기관용)

> [!warning] 호스트가 둘이다
> 기관용 키는 `apihub-pub.kma.go.kr` 에서만 동작한다. 예전 주소 `apihub.kma.go.kr` 에 쓰면 403 이다(`app/config.py` `KMA_HOST`).
> 키는 `authKey=` 인자로 보낸다.

- 발급처: 위 관리URL 로그인 → (여기에 실제로 누른 메뉴 경로를 적어 둘 것 — 찾기 어려워서 이 문서를 만든다)
- 같은 계정: (계정 아이디는 위 `계정:` 줄에. 비밀번호는 적지 않는다)

## API마다 따로 활용신청
키 하나로 되지 않고 **API 단위로 활용신청**이 필요하다. 신청 안 한 API 는 403 + "활용신청이 필요한" 문구가 온다.
- 예: `nph-sfc_obs_latlon_api` 는 403 — 그래서 격자 위경도는 `sfc_grid_latlon.nc` 로 대신했다.
- 새 API 를 붙이기 전에 여기 "신청한 API" 표에 먼저 적는다.
