# 공공데이터포털

> [!info] 키는 하나, 활용신청은 API 마다
> 일반 인증키(Decoding) 하나를 모든 API 에 쓴다. 대신 **API 마다 활용신청 → 승인**을 따로 받는다.
> 승인 전에는 "등록되지 않은 서비스키" 오류가 난다. 활용기간(만료)은 **API 별 신청 화면**에 적혀 있다 — 신청할 때마다 아래 표에 옮겨 적는다.
