# 브이월드 지오코더

- 지번 주소(산 번지 포함)를 필지 기준 점(위도 · 경도)으로 바꾼다. `type=PARCEL`, `crs=epsg:4326`.
- 발급: 브이월드 로그인 → 오픈API → 인증키 발급. 서비스 분류는 "지오코더", 활용 URL 은 `http://localhost`.
- ⚠️ 약관: 응답을 파일 · DB 에 저장하지 않는다 → 서버가 켜질 때마다 다시 묻는다(1,658곳 ≈ 2분). 받는 동안 · 못 찾은 곳은 읍면동 기준.
- 못 찾은 곳(섬 등)은 위키 `data/지구좌표_수동.csv`(지역ID,위도,경도)에 사람이 적는다 — 이건 저장해도 된다.
- 산사태 지구처럼 넓은 곳은 대표 필지 한 점이라 실제 위험 범위와 다를 수 있다.
