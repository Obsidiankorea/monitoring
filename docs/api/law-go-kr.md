# 법제처 국가법령정보 Open API

> [!info] 키 = 가입 아이디
> 인증키 `OC` 는 법제처 가입 **아이디**다. 따로 발급되는 긴 키가 아니다.

> [!warning] 호출하는 서버의 공인 IP 를 미리 등록해야 한다
> 이 PC 에서 시험하면 막힌다. 서버를 옮기거나 회선이 바뀌면 IP 를 다시 등록한다.

## 신청 때 고른 것
- 대상: 현행법령(`eflaw`), 행정규칙(`admrul`), 자치법규(`ordin`)
- 응답 형식: 목록 JSON (본문 HTML 은 안 쓴다)

## 주의
- 법령명은 가운뎃점이 `ㆍ`(U+318D) 다 — "풍수해ㆍ지진재해보험법". 보통 가운뎃점 `·` 로 치면 검색에 안 걸린다.
- 감시 대상 17건은 `config/law_watch.json`. 추가는 그 파일만 고친다.
