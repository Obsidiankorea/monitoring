# 다른 PC로 옮겨 이어서 작업하기

내부망 윈도 PC에서 포크해 이어 가기 위한 문서. **이 문서만 보고 돌릴 수 있게** 썼다.

## 1. 가져오기

```bash
git clone <저장소> gnweather
cd gnweather
```

⚠️ **저장소에 없는 것이 둘 있다.** `.gitignore`로 막아 뒀다.

| 없는 것 | 어떻게 채우나 |
|---|---|
| `config/api_keys.txt` | 기존 PC에서 **직접 복사**해 온다. 또는 `handoff-mac/config/api_keys.txt`가 함께 왔다면 실행 스크립트가 알아서 복사한다 |
| `data/gnweather.db`, `data/cache/` | 채울 필요 없다. 처음 뜰 때 다시 받는다(10~40초) |

`config/api_keys.txt` 형식:

```
ORG_API_KEY=<기상청 API허브 기관용 키>
```

## 2. 실행

| | |
|---|---|
| **윈도** | `run.bat` 더블클릭 |
| **맥** | `run.command` 더블클릭 |

스크립트가 가상환경 생성 · 의존성 설치 · 키 배치 · 빈 포트 찾기 · 브라우저 열기를 한다.
처음만 1~2분 걸린다.

파이썬이 없으면 [python.org](https://www.python.org)에서 3.12 이상을 설치하고
설치 화면의 **"Add python.exe to PATH"를 반드시 체크**한다.

직접 띄우려면:

```bat
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python -m app.main
```

포트를 바꾸려면 `set PORT=9000` 후 실행. 다른 기기에서도 보려면 `set HOST=0.0.0.0`.

## 3. 내부망에서 달라지는 것

### 기상청 API에 못 나가는 경우

수집기가 전부 실패하고 화면이 빈다. `data/gnweather.db`를 외부망 PC에서 만들어
복사해 오면 **읽기 전용 데모**로는 돌아간다. 정식으로는 프록시를 열거나,
`app/kma.py`의 호출부를 내부망 중계 주소로 바꾼다 — HTTP를 치는 곳은 그 파일 하나뿐이다.

### 평균강수량

**아직 구현하지 않았다.** 내부망에서 직접 받기로 해서 비워 뒀다.

- 화면: `metric === "avg"` 분기가 이미 있고, `stationsOf(sig)` 평균을 계산한다.
  서버에서 받아 온 값으로 바꾸려면 `app/web/static/index.html`의 `avgSeries()`를 고친다.
- 서버: `app/queries.py`에 `rain_avg()`를 추가하고 `/api/rain/avg`로 내보내면 된다.

## 4. 구조 — 어디를 고치면 되나

```
기상청 API ──▶ app/collectors/ ──▶ SQLite ──▶ app/queries.py ──▶ /api/* ──▶ 화면
               (APScheduler)      data/gnweather.db
```

| 하고 싶은 일 | 고칠 파일 |
|---|---|
| 새 기상청 API 붙이기 | `app/collectors/`에 파일 추가 + `app/main.py`의 `COLLECTORS`에 등록 |
| 저장 구조 바꾸기 | `app/db.py`의 `SCHEMA` |
| 화면에 줄 값 바꾸기 | `app/queries.py` |
| 수집 주기 | `app/config.py`의 `INTERVALS` |
| 예측 이미지 장수·간격 | 화면 메뉴에서 바꾼다(DB에 저장). 기본값은 `app/config.py`의 `QPF` |
| 시군·특보구역 규칙 | `app/domain/regions.py` |
| 화면 | `app/web/static/index.html` 한 파일 |

`app/web/static/index.html`은 **단일 파일**이다. 빌드 도구가 없어 열어서 고치면 끝난다.
`mockup/`에는 서버 없이 도는 표본 데이터판이 있다 — 화면만 손볼 때 쓴다.

## 5. 절대 어기면 안 되는 것

`handoff-mac/docs/05-pitfalls.md`가 원본이고, 그중 코드에 박혀 있는 것:

1. **조회 실패와 '자료 없음'을 구분한다.** 실패는 저장하지 않고 다음 주기에 다시 시도한다.
   DB의 `quality` 열, 화면의 `0.0` / `—` / `✕`가 그 구분이다.
   뭉개면 *전부 해제 → 전부 신규* 헛알림이 난다.
2. **비밀은 저장소에 넣지 않는다.** 코드의 기본값 딕셔너리에 넣는 것도 금지 — 커밋된다.
   로그도 조심한다. httpx가 요청 URL을 통째로 찍어 `authKey`가 남으므로 로거를 낮춰 뒀다.
3. **시각은 전부 KST.** UTC로 바꾸지 않는다.
4. **특보 레벨 문자열은 `주의`·`경보`다**(`주의보` 아님). 폭염은 `중대경보`까지 3단계이고
   레벨을 뗄 때 **긴 것부터** 떼야 `폭염중대경보`가 누락되지 않는다.
5. **RN1은 선행 1시간 누적**이라 값이 1시간 단위로만 바뀐다. 칸을 그냥 더하면 3배가 된다.
6. **예측 분포 API는 지역 크롭을 안 해 준다.** 전국을 받아 PIL로 자른다.
   크롭 박스는 소스마다 다르다.
7. **한꺼번에 많이 요청하면 중간이 통째로 실패한다.** 실측으로 확인했다(아래).

## 6. 실측으로 알아낸 것

문서에 없거나 문서와 다른 것. **추측이 아니라 실제로 불러 확인한 값이다.**

| 항목 | 실측 |
|---|---|
| 예측 이미지 동시 요청 | 36장을 한꺼번에 던지면 `ef=190~240` 6장이 통째로 실패. 순차 + 1회 재시도로 36/36 성공 |
| 예측 이미지 크기 | `size=1800` → 1835×1820, 장당 약 130KB. 경남만 크롭하면 장당 약 19KB |
| 크롭 박스 | `size=1800` 기준 경남 광역 `(660, 560, 1610, 1360)` |
| 발표 감지 | 미래 시각을 요청하면 **최신 발표분**이 온다. 이미지 왼쪽 아래 발표시각 표시를 해시해 비교하면 무강수라 강수역이 같아도 속지 않는다 |
| 발표 지연 | 측정 중 — `docs/02-발표주기.md` 참고 |
