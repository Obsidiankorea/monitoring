# 로그인 · 시군 화면 · 파견 현황

서버 하나에 화면만 계정에 따라 다르다. 시군이 보낸 현장 요청 · 회신이 같은 DB 에 쌓여 도 화면에 바로 보인다(두 서버를 띄우지 않는다).

## 역할

| 역할 | 할 수 있는 것 |
|---|---|
| 도 관리자 | 전부 + 계정(`/admin.html`) · 설정 · API 키 바꾸기 |
| 도 사용자 | 경남 전체 지도 · 상황판단 · 파견 현황 |
| 시군 사용자 | 자기 시군에 고정된 지도(둘레 시군은 어둡게 보기만) · 자기 시군 지구의 연락처 · 현장 요청 · 회신 · 파견 현황 |

- 코드: `app/auth.py`(계정 · 접속 · 요청 거르기), 미들웨어 `need_login`(`app/main.py`), 화면 `login.html` · `admin.html` · `board.html` · `js/12-auth.js`.
- 비밀번호는 scrypt 해시, 접속 쿠키는 sha256 만 DB(`app_user` · `app_session`)에. 14일 유지, 10번 틀리면 15분 막힘.

## 계정 신청 → 관리자 승인 · 시연

- **계정 신청**: 로그인 화면 › 계정 신청(아이디 · 이름 · 부서 · 소속 도/시군 · 비밀번호). 승인 전에는 비밀번호가 맞아도 '승인 기다리는 중'.
  관리자는 계정 관리 › **승인 기다리는 신청**에서 소속을 고쳐 승인하거나 거절(거절은 지운다). 신청은 30건까지 쌓인다.
  신청이 기다리면 관리자 화면의 **설정 단추에 빨간 점** · 설정 › 계정 탭에 빨간 '● 가입 신청 N건', 늘어날 때 알림(1분마다 `/api/auth/users` 확인).
- **처음 안내(튜토리얼)** — 계정으로 처음 들어오면 한 번(`js/13-tour.js`): 층 고르기 · 레이어 · 지도 색 · 어둡게/밝게(그 자리에서 바꾸기) · 오른쪽 위 강수 누적 · 지금 오는 비/예측 상위 · 지도 누르기 · 강수↔폭염 · 보고서 · 상황판단 · AI · 도움말 · 설정. 건너뛰기(Esc) · ← →. 끝내거나 건너뛰면 `gn-tour=done` — 계정 화면 저장에 따라가 다른 PC 에서도 다시 안 뜬다. 다시 보기: 설정 › 계정 › 처음 안내.
- **계정 조작은 설정(Ctrl+,) › 계정 탭** — 로그인한 사람 · 로그아웃 · 계정 관리(관리자) · 시군 화면 · 내 화면 저장 · 파견 현황 · 시연 화면. 아래 왼쪽 띠는 없앴다(화면을 덜 가리게) — 시군 화면으로 보는 중일 때만 '○○ 화면으로 보는 중 · 도 화면으로'.
- 예전 '비밀번호 없는 시군 접속'은 없앴다(2026-11-20, 공유기 포트를 연 뒤) — 남아 있던 손님 계정 · 접속은 서버가 뜰 때 지운다.
- **시연(8001 · GN_DEMO)**: 로그인 · 처음 설정 없이 늘 '시연 · 도 사용자'로 열린다(가짜 자료뿐).
  8000 의 로그인 화면 아래 · 설정 › 계정에 '시연 화면' 링크(같은 주소의 8001).
  시연의 연락처는 가짜 이름 · 번호(`contacts._fake`), 사람 기록(담당 · 회신 · 계정)은 굳힐 때 · 띄울 때 지우고
  가짜 파견 기록(`snaps.add_dispatch` — 특보 시군 지구에 조치 완료 · 조치 중 · 지원 필요 · 확인 없음)과 그 시각 단계 이력을 넣는다.
  선행 강우(5일)는 굳힌 72시간 앞 48시간을 72시간 뒤 정시 격자의 40%로 가짜로 채운다(`snaps.add_ante`, 사본에만).

## 처음 켤 때

> [!note] 계정이 없으면 예전처럼 열려 있다
> 첫 화면 아래 왼쪽 **처음 설정 — 관리자 만들기** → 로그인 화면의 처음 설정에서 만든 계정이 도 관리자가 된다.
> 관리자가 하나라도 생기면 처음 설정은 닫히고, 그때부터 로그인을 요구한다.

- 서버 안(127.0.0.1)에서 부르는 요청 · 이 PC 에서 켠 화면은 로그인 없이 관리자로 통과(판정 · AI 가 자기 자신을 부른다).
- 기계 열쇠 `GN_API_KEY`(api_keys · 환경변수, 머리 `X-GN-Key`) — 읽기만, 연락처 · 회신은 안 된다([[03-AI-상황판단]] 의 연락처 약속).
- 서버에서 계정 다루기: `docker exec -it gn-monitor python -m app.auth list | add <아이디> --role admin|do|sigun [--sigun 창원] | passwd <아이디>`

## 파견 현황(`/board.html`)

- `GET /api/reply/board?hours=24` — 최근 요청한 지구를 시군별로: 요청 · 열람 · 확인 · 조치 중 · 조치 완료 셈, 10분 넘게 확인 없음 · 지원 필요.
- 이름 · 번호는 넣지 않는다(사람은 상황판단 창의 회신 현황 — 잠금 뒤). 시군 사용자는 자기 시군만. 30초마다 새로.
- 현장 요청(연락처 · 링크 문자)은 도 · 시군 모두 보낸다(시군은 자기 시군 지구만). 요청 기록에 **보낸 곳 · 사람**('창원시 · 홍길동', 도는 '도 · 이름')이 남아
  현황판 '요청 · 보낸 곳' 칸 · 현장 화면 '요청' 단계에 보이고, 문자 머리글도 보낸 곳으로(`[창원시 재난상황실]` · `[경남도 재난상황실]`).

## 바깥에 열 때(공유기 포트 · 터널)

- 반복 호출 제한(사람마다 — 로그인 아이디, 없으면 주소): 로그인 20/10분 · 신청 5/1시간 · 현장 요청 120/10분 · 보고서 20/10분 · AI 질문 30/10분 → 429.
- 보안 머리글(nosniff · SAMEORIGIN · Referrer-Policy · Permissions-Policy), `server` 머리글 끔.
- 로그인 화면은 바깥 주소를 http 로 열면 '암호화되지 않은 주소' 경고. 시연(8001)은 AI 자유 질문을 받지 않는다(예상 질문만).
- **https 주소**: `https://gisang.day`(실황 :8000) · `https://demo.gisang.day`(시연 :8001) — Cloudflare 고정 터널 `gn`(2026-11-20).
  언레이드 `cf-gn` 컨테이너(host 망), 설정 · 인증서는 `/mnt/user/appdata/cloudflared-gn/`(config.yml · cert.pem · 터널 json — 저장소에 넣지 않는다).
  config 에 `httpHostHeader` 를 넣지 않는다(Host 를 localhost 로 바꾸면 관리자 통과). 쿠키 Secure 는 같은 망에서 온 `X-Forwarded-Proto: https` 로 판단(`main._https`).
  화면의 시연 ↔ 실황 링크는 포트 없는 주소면 `demo.` 를 붙이고 뗀다(`01-core.js` `TUNNEL` · `login.html`).
- 공유기 포트(8000 · 8001 · 8765)는 터널이 생겼으니 닫는다. 8765(재난상황보고서)는 바깥에 열 필요가 없다.

## 보기 방식(✥ 단추)

- 누르면 창: **시점** 꽉 차게 · 주변 함께(둘레 30%) · 경남 전체 / **시군 밖** 숨기기 · 흐리게 · 그대로 / 직접 조정(C, 예전 지도 위치).
- 숨기기 = 시군 밖 땅을 다 덮고(GL `selmask` 맨 위) 글자 · 관측소 · 지구 표시를 시군 둘레로 자른다(`#selclip`).
- 이 화면(브라우저)에 기억(`gn-view`). 시군 화면 기본은 꽉 차게 + 숨기기, 도 화면은 꽉 차게 + 흐리게.

## 관리자 · 도 사용자 — 시군 화면으로 보기

- 설정 › 계정 › **시군 화면** 고르기 → 주소 `?as=창원` 로 다시 열고 그 시군 담당자 화면처럼(고정 · 시군 밖 감추기 · 꽉 차게). 아래 왼쪽 '도 화면으로'(또는 같은 고르기)로 돌아온다.
- 화면만 시군처럼이다 — 연락처 · 파견 현황 같은 자료 범위는 내 계정 그대로(서버가 거르는 시군 제한은 실제 시군 계정으로만 확인된다).

## 화면 저장(설정 › 계정 › 내 화면)

- 화면 기억(층 · 창 위치 · 보기 방식 등 localStorage `gn-*`)은 브라우저 · 주소마다 따로다 — 새 PC · 새 주소(gisang.day)는 빈 채로 시작.
- **계정마다 마지막 화면 저절로** — 바뀐 것이 있으면 2분마다 · 창을 숨기거나 닫을 때 · 로그아웃할 때 `PUT /api/prefs`(저장 시각 `_at`). `prefs.js` 는 이 브라우저 기억의 주인(`gnv-owner`)이 다른 계정이면 지우고 이 계정 것으로, 같은 계정이어도 다른 PC 에서 더 늦게 저장했으면(`_at` > `gnv-at`) 그것으로 연다. 주인 표시가 없던 기억은 이 계정 것으로 삼는다.
- **내 화면으로 저장** → 계정에(`setting` 의 `view:<아이디>`). 기억이 하나도 없는 브라우저는 `map.html` 맨 앞의 `/api/prefs.js` 가 그것을 깔고 시작.
- 관리자 **모든 계정의 처음 화면으로** → `view:default` — 저장한 화면이 없는 사람의 시작 화면. **되돌리기**는 이 브라우저의 기억을 지우고 다시 연다.
- 연락처 잠금 번호(`gn-ct-pin`)는 올리지 않는다. 시연 사본에서는 계정마다 저장한 화면을 지운다(처음 화면만 남김). 이 PC(로컬)는 계정이 없어 쓰지 않는다.

## 현장 기록 — 도가 보는 곳

- 현장 스탬프 · 메모 · 사진은 지구마다 `duty_log` 에 쌓이고 지우지 않는다(고친 것도 새 줄).
- 상황판단 지구 상세 › 현장 회신 › **이 지구 기록 전부** — 지난 요청까지(`GET /api/reply/history?rid=`, 잠금 번호 뒤, 시군은 자기 지구만).
- 지도에서 지구를 눌러 고정한 카드 › 담당 › **✉ 문자 내역** — 같은 기록. 맨 위에 **중요한 조치**(★): 조치 완료 · 지원 필요 · 사진, 메모에 대피 · 통제 · 침수 · 고립 · 피해 같은 말이나 'N명 · N세대'(`reply.IMP_WORDS`).
- AI 상황판단 보고 · 자유 질문은 '중요한 점' 뒤 **현장 조치 — 문자 회신(최근 24시간)** 칸을 근거로 본다(`GET /api/field/actions`). 이름 · 번호 · 메모 글은 넘기지 않고 단계 · 지원 필요 · 미확인 · 메모에서 뽑은 낱말(대피 · 12명 …)만.
- 파견 현황판 지구 줄 — 마지막 조치 메모 · 📷(잠금 번호가 맞을 때만, 지도에서 넣은 번호를 같이 쓴다).
- 판단 기록 › 지난 호우 — 단계 · ✍ 판단 · 📨 현장 요청 · 회신을 시각 순으로(이름 · 메모 글 없이 📝 · 📷 표시만).
- 문자 보내기 창의 **직접 입력** — 표의 번호가 틀렸거나 다른 사람에게 보낼 때. 번호는 저장하지 않는다.
