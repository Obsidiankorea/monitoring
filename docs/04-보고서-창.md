# 보고서 창 — 한글 보고서 · 그림 받기 · 텔레그램

지도 오른쪽 위 도구 줄의 **맨 왼쪽 문서 단추**로 연다. 언레이드의 재난상황보고서 서버(jaenan-weather, `:8765`)가 만드는 한글 파일(.hwp)과 그림(움짤 · 종합 · 특보 · 기온표)을 타일로 골라 **받거나 텔레그램으로 보낸다**.

> [!important] 한 줄 요약
> 보고서 목록은 `app/reports.py` 의 등록부 `REG` 한 곳에 있다 — **보고서가 늘면 거기 한 줄**. 화면은 그 목록을 그대로 그린다.

## 1. 흐름

| 무엇 | 어디서 | 코드 |
|---|---|---|
| 목록 · 연결 준비 | `GET /api/reports` | `app/reports.py` `listing()` |
| 만들기 · 받기 | `POST /api/reports/run` `{id, opts, items, tg, dl}` → jaenan `GET /api/run/<작업>`(작성 창 보고서는 `POST` — 고른 문구를 본문 JSON 으로) → `GET /files/<이름>` | `fetch()` · `run()` |
| 여러 파일 | 한글 보고서는 .hwp 하나, 그림 작업은 만든 파일 전부. 받기는 **둘 이상이면 zip 하나**(`bundle()`) | `fetch()` · `bundle()` |
| 텔레그램 | gn-monitor 가 직접, **파일마다** — PNG 는 `sendPhoto` · GIF 는 `sendAnimation` · 그 밖(.hwp)은 `sendDocument`. 설명 글은 첫 장에만 | `send_tg()` |
| 문구 후보 | `GET /api/reports/phrases` → jaenan `GET /api/phrases/meeting`(5분 캐시) | `phrases()` |
| 자료 기준 시각 | jaenan 응답 `basis`(쓴 기상청 자료의 발표 · 기준 시각) + 이번 요청에 넣은 우리 자료(수위 · 우려지역 판정 · 특보 · 조위) 시각 → 받기는 머리 `X-Basis`(퍼센트 인코딩 JSON), 텔레그램만은 JSON `basis` → 화면 팝업 | `fetch(meta=)` · `repBasis()` |
| 화면 | 타일(썸네일 + 이름 + 설명), 구석 텔레그램 단추, ⚙ 설정 · 옵션 · 작성 창 | `app/web/static/js/08b-reports.js` |

- jaenan 은 **한 번에 한 작업**(서버 잠금) · 같은 인자는 2분 캐시. 풍수해보고는 1분 안팎이라 300초까지 기다린다. 만드는 동안 다른 타일은 눌리지 않는다.
- 받을 때 텔레그램에도 보낼지는 창 머리의 ⚙(전체 설정). **보고서별 옵션은 타일을 오른쪽 눌러**(메뉴 키 · Shift+F10 · 타일의 작은 ⚙) 여는 옵션창에서 — 런처(윈도우 앱) 옵션 가운데 서버에서 되는 것만. **그 브라우저에** 보고서별로 기억하고, 보낼 때는 기본값과 다른 것만 보낸다(안 보낸 것은 서버 설정). 기본값과 다른 옵션이 있으면 타일에 「옵션」 표시.
- 시연(DEMO) 화면에서는 목록만 보이고 만들지 않는다(작성 창은 열리지만 문구 후보를 안 부르고 만들기 단추가 꺼진다).

> [!warning] 키
> 주소 · 토큰은 `config/api_keys.txt` 의 `JAENAN_URL`(비우면 `http://100.106.116.92:8765`) · `JAENAN_TOKEN`, 텔레그램은 `TELEGRAM_BOT_TOKEN` · `TELEGRAM_CHAT_ID`(알림과 같은 것). 토큰은 응답 · 로그 · 오류 글 어디에도 나가지 않는다. 키 문서는 [[jaenan]] · [[telegram]].

## 3. 상황판단회의 작성 창

타일을 누르거나(오른쪽 누름 · ⚙ 도 같다) 작성 창이 열린다.

| 칸 | 하는 일 |
|---|---|
| 재난 종류 칩 | 호우 · 태풍 · 강풍 · 풍랑 · 대설 · 한파 · 폭염 여러 개. 문구 후보를 거른다(안 고르면 전부 · 고른 문구는 늘 보인다), 제목 제안, 서버의 특보 이력 종류 |
| 회의 제목 | 제안 「11. 17.~18. 호우·강풍 대비」(기간을 안 넣으면 오늘~내일). 고치면 그대로 두고, 「제안으로 돌리기」 |
| 기간 | 비우면 서버 기본(전일 00시 ~ 지금) |
| 중점 유의사항 · 조치계획 | 탭 둘(옆 숫자 = 고른 개수). 왼쪽은 고른 것만 보내는 차례로 번호 — ✎ 로 글 · 세부(`- …`) · 주석(`※ …`)을 고치고(`**…**` 는 굵게) ✕ 로 뺀다, [직접 쓰기]. 후보는 [+ 문구 고르기]로 오른쪽에서 덮어 나오고(» · Esc · 바깥 누름으로 닫는다), 종류별로 묶어 검색 · 종류 칩으로 거르며 누르면 바로 왼쪽으로. 유의사항은 7개 막대(넘치면 주황) |
| 머리 요약 줄 | 프리셋 불러오기 · 제목 · 종류 · 기간 · 자료 개수를 한 줄로. 회의(종류 · 제목 · 프리셋 저장) · 기간 · 자료는 [설정 ▾] 을 펴서. 기간 칸은 서버 기본(전일 00시 ~ 지금)으로 미리 채워 보이고, 그대로 두면 저장하지 않아 다음에 열 때 그때 기준으로 다시 채운다 |
| 특보 시군 자료(자동) | 체크 셋(기본 켬) — 특보지역 현황 · 과거 유사 사건 · 조위 현황. 내용은 지도 서버가 만든다(편집 없음, 아래) |
| [만들어 받기] · [텔레그램으로] | 보내는 차례 = 문구 파일 차례, 그다음 직접 추가한 것(끌어 옮기기 없음) |

- 고른 것 · 고친 글 · 종류 · 제목 · 기간은 **그 브라우저에** 기억한다(`localStorage gn-rep` 의 `cm` · `opts.meeting`).
- **하천 수위**(`river_rows`) — 서식 열 차례 10곳의 현수위 · 단계 · 기준 수위(홍수통제소 제원 thr) · 관측 시각 · 늦음. 성하리 · 일중리는 경남 밖 위쪽 지점이라 `river.UP_WL` 로 따로 받는다.
- **특보 시군 자료 셋**(`app/meeting.py`) — 특보 시군 = 지도 특보 자료(`queries.alerts`)의 호우 · 태풍 · 강풍 · 풍랑 · 대설 · 한파 · 폭염(+예비) 시군. 없으면 「발효 중인 특보 없음」.
  - 우려지역: 위키 인명피해 우려지역(유형 가족별 지구 수) · 지형 표(지구 둘레 100m · 300m 건물, 오래된 약한 구조 — 지구끼리 겹쳐 셈) · 상황판단 판정 캐시(`judge._BC` 경남 전체, **새로 세지 않는다** — 없으면 그 줄 생략). 이름 · 연락처는 쓰지 않는다.
  - 과거 사례: 위키 `data/경남 풍수해 사건×시군 피해.csv` · `경남 풍수해 사건 이력.csv` 의 A 등급(복구계획 2016~) 사건, 종류가 맞는 것 먼저 · 피해액 큰 것 둘 — 위키 [[과거 사례 찾는 법 (상황판단회의)]] 규칙.
  - 조위: 태풍 · 풍랑 · 호우 특보가 있거나 특보 시군에 해안 시군이 있을 때만 — 다음 만조 · 고조정보 단계 · 지반고에 닿는 시설 · 대조기.
  - 묶음마다 끝에 `※` 출처 · 기준 시각 줄. 끈 묶음 · 해당 없는 조위는 본문에 안 넣고, 재난상황보고서 서버가 소제목째 지운다.
- **자료 기준 시각 팝업** — 만들기가 끝나면(받기 · 텔레그램) 이번 문서에 쓴 기상청 자료의 발표 · 기준 시각을 작은 창으로(닫기 · Esc · 바깥). 기상청 시각은 문서에 넣지 않는다. 지금 시각을 내는 작업은 상황판단회의 · 풍수해보고뿐(다른 보고서 · 그림은 서버가 아직 안 모은다 — 팝업이 안 뜬다). 17시 대기 파일은 팝업 없음.
- 문구 후보 파일은 재난상황보고서 저장소 `template/상황판단회의_문구.json`(사용자 원본 + 행안부 · 보도에서 모은 후보). 서식에 들어가는 모양은 그쪽 문서 「상황판단회의 서식」.

## 4. 17시 대기 (기상상황보고)

옵션창의 「17시 발표 대기 걸기」 — 통보문 · 단기예보(육상)가 **오늘 17시 발표**로 나올 때까지 기다렸다가 17시 기준으로 만든다(런처의 [17시 대기]와 같은 판정).

| 누가 | 무엇 |
|---|---|
| jaenan | `wait1700=1` 이면 발표가 아직일 때 **만들지 않고 바로** `waiting` 으로 답한다(기다리지 않는다 — 한 번에 한 작업이라) |
| gn-monitor | 서버 스케줄러가 **1분마다** 묻는다(`reports.wait_tick`). 나오면 파일을 `STATE/reports/` 에 두고(하루 뒤 지움), 「나오면 텔레그램으로」면 보낸다. 18:30 까지 안 나오면 그만두고 사유를 남긴다. 상태는 `STATE/reports_wait.json` — 다시 떠도 이어진다 |
| 화면 | 타일에 시계 배지 「17시 대기 중」(취소) → 「✓ 17시 보고서 준비됨 — 눌러 받기」. 도구 줄 보고서 단추에도 점(대기 중 · 준비됨, 툴팁 글도 바뀐다) |

- 오늘 17시 것만 — 18:30 뒤에 걸면 이미 나왔을 것이라 바로 한 번 만든다. 다음 날로 넘어가는 대기는 없다.
- 등록부의 `"wait": True` 로 켠다 — 일일상황보고도 같은 엔진이라 한 줄로 켤 수 있다(지금은 기상상황보고만).
- 시연(DEMO)에서는 걸지 않는다. API: `GET · POST · DELETE /api/reports/wait`, `GET /api/reports/wait/file?id=`.

## 로고

창 머리 ⚙(전체 설정)의 **로고** — 보고서 `[로고]` 칸에 넣을 그림을 작은 그림과 이름으로 보여 주고 하나 고른다(지금 고른 것에 ✓), [로고 추가] 로 올린다(PNG · JPG · WEBP, 2MB 이하 — 이쪽에서 한 번, 재난상황보고서 서버가 다시 보고 PNG 로 바꿔 `/config/logos/` 에 둔다). 고르기는 **서버 설정**이라 모두에게 같다. gn-monitor 는 jaenan 의 `/api/logos` 를 대신 부른다(`/api/reports/logos` · `/selected` · `/img`, 토큰은 서버 안에만). 시연에서는 안 된다. 칸 값 · 서식에 칸을 더하는 법은 재난상황보고서 문서 「로고와 서식 칸」.

## 5. 보고서 한 줄 더하기

1. jaenan 쪽에 작업이 있는지 본다(재난상황보고서 저장소 `server/jobs.py` 의 `작업들`). 없으면 그쪽에서 먼저 만든다.
2. `app/reports.py` 의 `REG` 에 한 줄:
   ```python
   {"id": "heat", "name": "폭염 상황보고", "group": "폭염", "job": "heat", "desc": "한 줄 설명", "opts": [], "ready": True},
   ```
   - `group` 은 `GROUPS`(풍수해 · 폭염 · 일상 · 긴급 · 그림) 가운데 — 새 묶음이면 `GROUPS` 에도.
   - `opts` 는 옵션창에 그릴 것 — `_o(key, label, kind, default, sec, hint, …)`, kind 는 `datetime` · `int`(min · max) · `choice`(values) · `multi`(values) · `bool` · `text`(max). 키 · 범위는 jaenan `server/jobs.py` 의 `인자정의` 와 맞춘다(그쪽이 다시 확인하고 모르는 것은 버린다).
   - 아직 서버에 없으면 `"job": ""`, `"ready": False` — 「준비 중」 타일(눌리지 않음).
   - 고른 글을 함께 보내야 하면 `"compose": "<이름>"` — 지금은 `meeting`(상황판단회의 작성 창)뿐.
3. 썸네일(있으면): `app/web/static/img/reports/<id>.png` — 가로 400px 안팎(타일은 A4 세로 비율로 위쪽을 잘라 보인다). 없으면 문서 모양 자리표시가 나온다.

> [!tip] 썸네일 만드는 법(2026-11-16 · 17)
> NAS jaenan 컨테이너에서 실제로 만든 파일로 — 한글은 `rhwp export-png <파일> -p 0 --dpi 48`(쪽 번호는 0부터)로 첫 쪽, 그림은 그대로(GIF 는 첫 장). 흰 바탕 · 397×562 로 맞춰 자르고 48~96색으로 줄였다(Pillow). 이 PC 의 한글은 쓰지 않았다.

## 6. 이번에 뺀 것
- 그림 작업 가운데 `rain`(실측) · `forecast`(예측) 타일 — 요청에 없어서.
- 런처 옵션 가운데 서버에서 안 되는 것 — 스방(내부망) 강우 · 다우지점 출처, 강우/강풍 보고서 기준, 한글 COM 전용(열린 문서 고치기 · 06시 기온만), 그림 범위 조정 창(누적강수 · 레이더), 강풍 표(스방), 데모 고르기, 일일 강수 기간(서버는 전일 00시~지금).
- 상황판단회의 작성 창의 끌어 옮기기 · 런처(윈도우) 쪽 작성 화면.
