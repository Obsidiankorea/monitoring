# 보고서 창 — 한글 보고서 받기 · 텔레그램

지도 오른쪽 위 도구 줄의 **맨 왼쪽 문서 단추**로 연다. 언레이드의 재난상황보고서 서버(jaenan-weather, `:8765`)가 만드는 한글 파일(.hwp)을 타일로 골라 **받거나 텔레그램으로 보낸다**.

> [!important] 한 줄 요약
> 보고서 목록은 `app/reports.py` 의 등록부 `REG` 한 곳에 있다 — **보고서가 늘면 거기 한 줄**. 화면은 그 목록을 그대로 그린다.

## 1. 흐름

| 무엇 | 어디서 | 코드 |
|---|---|---|
| 목록 · 연결 준비 | `GET /api/reports` | `app/reports.py` `listing()` |
| 만들기 · 받기 | `POST /api/reports/run` `{id, opts, tg, dl}` → jaenan `GET /api/run/<작업>` → `GET /files/<이름>` | `run()` |
| 텔레그램 | gn-monitor 가 직접 `sendDocument` | `send_tg()` |
| 화면 | 타일(썸네일 + 이름 + 설명), 구석 텔레그램 단추, ⚙ 설정 | `app/web/static/js/08b-reports.js` |

- jaenan 은 **한 번에 한 작업**(서버 잠금) · 같은 인자는 2분 캐시. 풍수해보고는 1분 안팎이라 300초까지 기다린다. 만드는 동안 다른 타일은 눌리지 않는다.
- 받을 때 텔레그램에도 보낼지, 보고서별 옵션(긴급상황보고의 기준 시각 등)은 창의 ⚙ 에서 — **그 브라우저에만** 기억한다.
- 시연(DEMO) 화면에서는 목록만 보이고 만들지 않는다.

> [!warning] 키
> 주소 · 토큰은 `config/api_keys.txt` 의 `JAENAN_URL`(비우면 `http://100.106.116.92:8765`) · `JAENAN_TOKEN`, 텔레그램은 `TELEGRAM_BOT_TOKEN` · `TELEGRAM_CHAT_ID`(알림과 같은 것). 토큰은 응답 · 로그 · 오류 글 어디에도 나가지 않는다. 키 문서는 [[jaenan]] · [[telegram]].

## 2. 보고서 한 줄 더하기

1. jaenan 쪽에 작업이 있는지 본다(재난상황보고서 저장소 `server/jobs.py` 의 `작업들`). 없으면 그쪽에서 먼저 만든다.
2. `app/reports.py` 의 `REG` 에 한 줄:
   ```python
   {"id": "heat", "name": "폭염 상황보고", "group": "폭염", "job": "heat", "desc": "한 줄 설명", "opts": [], "ready": True},
   ```
   - `group` 은 `GROUPS`(풍수해 · 폭염 · 일상 · 긴급) 가운데 — 새 묶음이면 `GROUPS` 에도.
   - `opts` 는 받을 때 고를 것 `{key, label, kind: "datetime"|"text", hint}` — ⚙ 설정에 칸이 생기고, 그 키만 jaenan 에 넘어간다(`datetime` 은 `YYYYMMDDHHMM` 열두 자리로 맞춘다).
   - 아직 서버에 없으면 `"job": ""`, `"ready": False` — 「준비 중」 타일(눌리지 않음).
3. 썸네일(있으면): `app/web/static/img/reports/<id>.png` — 첫 쪽 그림, 가로 400px 안팎. 없으면 문서 모양 자리표시가 나온다.

> [!tip] 썸네일 만드는 법(2026-11-16)
> NAS 에서 실제로 만든 한글 파일을 jaenan 컨테이너 안의 `rhwp export-png <파일> -p 0 --dpi 48 -o <폴더>`(쪽 번호는 0부터)로 첫 쪽 PNG 로 그리고, 흰 바탕 · 48색으로 줄여(Pillow) 넣었다. 이 PC 의 한글은 쓰지 않았다.

## 3. 이번에 뺀 것
- 그림 작업(gif · combo · rain · forecast · alert)은 이 창에 넣지 않았다 — 한글 보고서만.
