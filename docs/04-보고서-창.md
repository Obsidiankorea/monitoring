# 보고서 창 — 한글 보고서 받기 · 텔레그램

지도 오른쪽 위 도구 줄의 **맨 왼쪽 문서 단추**로 연다. 언레이드의 재난상황보고서 서버(jaenan-weather, `:8765`)가 만드는 한글 파일(.hwp)을 타일로 골라 **받거나 텔레그램으로 보낸다**.

> [!important] 한 줄 요약
> 보고서 목록은 `app/reports.py` 의 등록부 `REG` 한 곳에 있다 — **보고서가 늘면 거기 한 줄**. 화면은 그 목록을 그대로 그린다.

## 1. 흐름

| 무엇 | 어디서 | 코드 |
|---|---|---|
| 목록 · 연결 준비 | `GET /api/reports` | `app/reports.py` `listing()` |
| 만들기 · 받기 | `POST /api/reports/run` `{id, opts, tg, dl}` → jaenan `GET /api/run/<작업>` → `GET /files/<이름>` | `run()` |
| 텔레그램 | gn-monitor 가 직접 `sendDocument` | `send_tg()` |
| 화면 | 타일(썸네일 + 이름 + 설명), 구석 텔레그램 단추, ⚙ 설정 | `app/web/static/js/08b-reports.js` |

- jaenan 은 **한 번에 한 작업**(서버 잠금) · 같은 인자는 2분 캐시. 풍수해보고는 1분 안팎이라 300초까지 기다린다. 만드는 동안 다른 타일은 눌리지 않는다.
- 받을 때 텔레그램에도 보낼지는 창 머리의 ⚙(전체 설정). **보고서별 옵션은 타일을 오른쪽 눌러**(메뉴 키 · Shift+F10 · 타일의 작은 ⚙) 여는 옵션창에서 — 런처(윈도우 앱) 옵션 가운데 서버에서 되는 것만. **그 브라우저에** 보고서별로 기억하고, 보낼 때는 기본값과 다른 것만 보낸다(안 보낸 것은 서버 설정). 기본값과 다른 옵션이 있으면 타일에 「옵션」 표시.
- 시연(DEMO) 화면에서는 목록만 보이고 만들지 않는다.

> [!warning] 키
> 주소 · 토큰은 `config/api_keys.txt` 의 `JAENAN_URL`(비우면 `http://100.106.116.92:8765`) · `JAENAN_TOKEN`, 텔레그램은 `TELEGRAM_BOT_TOKEN` · `TELEGRAM_CHAT_ID`(알림과 같은 것). 토큰은 응답 · 로그 · 오류 글 어디에도 나가지 않는다. 키 문서는 [[jaenan]] · [[telegram]].

## 2. 17시 대기 (기상상황보고)

옵션창의 「17시 발표 대기 걸기」 — 통보문 · 단기예보(육상)가 **오늘 17시 발표**로 나올 때까지 기다렸다가 17시 기준으로 만든다(런처의 [17시 대기]와 같은 판정).

| 누가 | 무엇 |
|---|---|
| jaenan | `wait1700=1` 이면 발표가 아직일 때 **만들지 않고 바로** `waiting` 으로 답한다(기다리지 않는다 — 한 번에 한 작업이라) |
| gn-monitor | 서버 스케줄러가 **1분마다** 묻는다(`reports.wait_tick`). 나오면 파일을 `STATE/reports/` 에 두고(하루 뒤 지움), 「나오면 텔레그램으로」면 보낸다. 18:30 까지 안 나오면 그만두고 사유를 남긴다. 상태는 `STATE/reports_wait.json` — 다시 떠도 이어진다 |
| 화면 | 타일에 시계 배지 「17시 대기 중」(취소) → 「✓ 17시 보고서 준비됨 — 눌러 받기」. 도구 줄 보고서 단추에도 점(대기 중 · 준비됨, 툴팁 글도 바뀐다) |

- 오늘 17시 것만 — 18:30 뒤에 걸면 이미 나왔을 것이라 바로 한 번 만든다. 다음 날로 넘어가는 대기는 없다.
- 등록부의 `"wait": True` 로 켠다 — 일일상황보고도 같은 엔진이라 한 줄로 켤 수 있다(지금은 기상상황보고만).
- 시연(DEMO)에서는 걸지 않는다. API: `GET · POST · DELETE /api/reports/wait`, `GET /api/reports/wait/file?id=`.

## 로고

창 머리 ⚙(전체 설정)의 **로고** — 보고서 `[로고]` 칸에 넣을 그림을 작은 그림과 이름으로 보여 주고 하나 고른다(지금 고른 것에 ✓), [로고 추가] 로 올린다(PNG · JPG · WEBP, 2MB 이하 — 이쪽에서 한 번, 재난상황보고서 서버가 다시 보고 PNG 로 바꿔 `/config/logos/` 에 둔다). 고르기는 **서버 설정**이라 모두에게 같다. gn-monitor 는 jaenan 의 `/api/logos` 를 대신 부른다(`/api/reports/logos` · `/selected` · `/img`, 토큰은 서버 안에만). 시연에서는 안 된다. 칸 값 · 서식에 칸을 더하는 법은 재난상황보고서 문서 「로고와 서식 칸」.

## 3. 보고서 한 줄 더하기

1. jaenan 쪽에 작업이 있는지 본다(재난상황보고서 저장소 `server/jobs.py` 의 `작업들`). 없으면 그쪽에서 먼저 만든다.
2. `app/reports.py` 의 `REG` 에 한 줄:
   ```python
   {"id": "heat", "name": "폭염 상황보고", "group": "폭염", "job": "heat", "desc": "한 줄 설명", "opts": [], "ready": True},
   ```
   - `group` 은 `GROUPS`(풍수해 · 폭염 · 일상 · 긴급) 가운데 — 새 묶음이면 `GROUPS` 에도.
   - `opts` 는 옵션창에 그릴 것 — `_o(key, label, kind, default, sec, hint, …)`, kind 는 `datetime` · `int`(min · max) · `choice`(values) · `multi`(values) · `bool` · `text`(max). 키 · 범위는 jaenan `server/jobs.py` 의 `인자정의` 와 맞춘다(그쪽이 다시 확인하고 모르는 것은 버린다).
   - 아직 서버에 없으면 `"job": ""`, `"ready": False` — 「준비 중」 타일(눌리지 않음).
3. 썸네일(있으면): `app/web/static/img/reports/<id>.png` — 첫 쪽 그림, 가로 400px 안팎. 없으면 문서 모양 자리표시가 나온다.

> [!tip] 썸네일 만드는 법(2026-11-16)
> NAS 에서 실제로 만든 한글 파일을 jaenan 컨테이너 안의 `rhwp export-png <파일> -p 0 --dpi 48 -o <폴더>`(쪽 번호는 0부터)로 첫 쪽 PNG 로 그리고, 흰 바탕 · 48색으로 줄여(Pillow) 넣었다. 이 PC 의 한글은 쓰지 않았다.

## 4. 이번에 뺀 것
- 그림 작업(gif · combo · rain · forecast · alert)은 이 창에 넣지 않았다 — 한글 보고서만.
- 런처 옵션 가운데 서버에서 안 되는 것 — 스방(내부망) 강우 · 다우지점 출처, 강우/강풍 보고서 기준, 한글 COM 전용(열린 문서 고치기 · 06시 기온만), 그림 범위 조정 창(누적강수 · 레이더), 강풍 표(스방), 데모 고르기, 일일 강수 기간(서버는 전일 00시~지금).
