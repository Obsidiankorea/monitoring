## 다음에 할 것

1. **앞으로 내릴 눈** — 단기예보 신적설(SNO)로 시군별 예상 적설. 고립예상마을 사전경보(12 · 24시간 10cm)와 잇는다.
2. **시군 대설 비상단계** — 시군 매뉴얼의 대설 진입 기준을 위키에 넣으면 바로 붙인다(지금은 통영만).
3. **적설 대피판단기준** — 20~25cm 출입통제 준비 · 30cm 대피 알림(대설 종합대책 원문 표 대조 뒤).
4. **현장 위치 목록** — 고립예상마을 56 · 중점관리 위험구역 91곳을 지도에 올린다(위치 목록이 필요하다).
