# 키 파일 틀 — 저장소에 들어 있는 건 이 예시뿐이다.
# run.bat / run.command 가 이 파일을 api_keys.txt 로 복사해 편집기로 연다.
# 아래 '여기에기상청API허브기관용키' 자리에 키를 붙여 넣고 저장하면 된다(따옴표 없이).
ORG_API_KEY=여기에기상청API허브기관용키

# (선택) AI 상황판단 자유 질문 — Anthropic API 키(console.anthropic.com › API Keys). 넣으면 '자동'이 Claude API 로 답한다. 없으면 예상 질문(규칙)만 답한다.
#   쓴 만큼 크레딧이 줄어든다. Console › Limits 에서 월 한도를 걸어 두기를 권한다.
# ANTHROPIC_API_KEY=여기에AnthropicAPI키
# (선택) 모델 — 없으면 claude-opus-5-5. 싸게: claude-sonnet-5-5 또는 claude-haiku-5-5
# ANTHROPIC_MODEL=claude-opus-5-5

# (선택) 법령 변경 감시 — 법제처 국가법령정보 Open API 인증키(OC = 가입 아이디). 서버 공인 IP 를 법제처에 등록해야 한다. 없으면 감시를 건너뛴다.
# LAW_OC=여기에법제처OC

# (선택) 하천 수위 · 댐 · 보 — 한강홍수통제소(HRFCO) OpenAPI 인증키(hrfco.go.kr 오픈 API › 인증키). 전국 4대강 홍수통제소 자료를 모아 준다. 없으면 지도 레이어 '하천 · 댐'(D)이 꺼진다.
# HRFCO_KEY=여기에홍수통제소키

# (선택) 지하차도 침수 위험 경보 — 국가교통정보센터 재난상황정보 키. 월 1000건이라 NAS 서버 한 곳에만 넣는다.
# ITS_KEY=여기에재난상황정보키

# (선택) 산림청 산사태 예보 — 공공데이터포털(data.go.kr) 활용신청 승인 뒤 받는 일반 인증키(Decoding). 없으면 산림청 조건은 '모름'으로 둔다.
# DATA_GO_KR_KEY=여기에공공데이터포털키
